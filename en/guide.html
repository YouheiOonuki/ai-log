▶ Open AI Chat Log to Markdown

How to use it

What this page covers: how to get your export, and what the Markdown files look like.

  1. Export your data from ChatGPT or Claude and download the zip.
  2. Choose the zip with "Choose zip or json". You can choose both.
  3. Check the count. Filter by title or date if you like.
  4. Download the Markdown zip or one combined Markdown file.

How to export ChatGPT and Claude chats

In ChatGPT, open Settings and go to Data controls. In Claude, open Settings and go to Privacy. Both send a download link by email that expires after 24 hours.

More details
  • Claude exports work on the web app or Claude Desktop, not in the iOS or Android app (official help).
  • Inside the zip, only conversations.json is read (large ChatGPT exports may split it into conversations-000.json and so on). Images and users.json are not read.

What the Markdown files contain (for Obsidian)

Each chat becomes one file named "date created title.md". The frontmatter holds the title, source, chat ID, created and updated times, model and message count.

  • Messages are "## User (time)" headings or Obsidian callouts. Code blocks are kept as they are.
  • If you edited or regenerated a message, only the branch you last viewed is written.
  • Images and attachments are listed by name only. Characters that Windows or macOS do not allow in file names become _.

Based on official help pages and on samples and code from public converters (MIT). Last checked October 1, 2026.

Sources

    OpenAI and Anthropic do not publish a specification for the export, so the format was checked against public converters. If your export does not load, let us know through the feedback form.

    FAQ

    How do I export ChatGPT conversations to Obsidian?
    Choose your ChatGPT export zip on this page, download the Markdown zip, and unzip it into your Obsidian vault. Each chat becomes one file, with title, dates and model in the frontmatter (properties).
    How do I open conversations.json?
    conversations.json packs every chat into one long line of JSON, so it is hard to read as is. Choose it on this page to get one readable Markdown file per chat.
    Are images and attachments included?
    No. The Markdown lists the file names only. The images and files themselves, and any text extracted from attachments in a Claude export, are left out.

    Notes and your data

    • Your files: The files you choose are read in this browser only and never uploaded. Nothing is saved, and everything is gone when you close the page. The page loads ad and analytics scripts, but they never receive your chats.
    • The downloaded files: The Markdown contains your full chats. Check them before you share them.
    • Format changes: The export format can change without notice. Anything that could not be read is listed under "List and notes" with the file name and line.
