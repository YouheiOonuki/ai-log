▶ AI 会話ログ Markdown 変換 を使う

使い方

  1. ChatGPT か Claude でデータを書き出し、zip をダウンロードする
  2. 「zip か json を選ぶ」で zip を選ぶ（両方まとめて選べる）
  3. 件数を見て、要るなら題名・期間で絞り込む
  4. Markdown（zip）か、1 つにまとめた Markdown をダウンロードする

ChatGPT・Claude の会話をエクスポートする方法

ChatGPT は設定の「データコントロール」から、Claude は設定の「プライバシー」から書き出します。どちらもリンクがメールで届き、24 時間で切れます。

もう少しくわしく
  • Claude の書き出しは Web 版かデスクトップ版から。iOS・Android のアプリからはできません（公式ヘルプ）。
  • zip の中で読むのは conversations.json（ChatGPT は分かれて conversations-000.json などになることがある）だけです。画像や users.json は読みません。

Markdown の中身（Obsidian で使う形）

会話 1 つが 1 ファイルで、ファイル名は「作った日 題名.md」です。題名・出どころ・会話 ID・作成と更新の日時・モデル・発言の数を frontmatter に書きます。

  • 発言は「## ユーザー（日時）」の見出しか、Obsidian のコールアウトで書きます。コードブロックはそのまま残します。
  • 編集・再生成で枝が分かれた会話は、最後に見ていた枝だけを書きます。
  • 画像・添付は名前だけ書きます。Windows・macOS で使えない文字はファイル名で _ に替えます。

形式の根拠: 公式ヘルプと、公開の変換器（MIT）の試料とコード。最終確認日 2026年10月1日。

確かめた先（出典）

    OpenAI・Anthropic は書き出しの中身の仕様を公開していないため、形式は公開の変換器で確かめました。形が変わって読めないときは、ご要望フォームで教えてください。

    よくある質問

    ChatGPT の会話を Obsidian に入れるには？
    ChatGPT の書き出しの zip をこのページで選び、Markdown（zip）をダウンロードして、展開したフォルダを Obsidian の保管庫に入れます。会話ごとに 1 ファイルで、題名・日時・モデルは frontmatter（プロパティ）に入ります。
    conversations.json の開き方がわからない
    conversations.json は全部の会話が 1 行に詰まった JSON で、そのままでは読みにくいファイルです。このページで選ぶと、会話ごとの読める Markdown になります。
    画像や添付ファイルも保存されますか？
    Markdown にはファイルの名前だけを書き、画像や添付の中身は入れません。Claude の書き出しにある添付の抜き出し文も入れません。

    ご利用上の注意・データの扱い

    • ファイル：選んだファイルはこのブラウザの中で読むだけで、外部に送信しません。ファイルも設定もブラウザに保存せず、ページを閉じると消えます。ページには広告とアクセス解析のスクリプトがありますが、会話の中身は渡しません。
    • 書き出したファイル：Markdown には会話の全文が入ります。共有する前に中身を確かめてください。
    • 結果の扱い：書き出しの形は予告なく変わることがあります。読めなかった所は画面の「一覧と注意」にファイル名と行で出します。

    ご要望・不具合の報告（Google フォーム）：いただいた内容をもとに直します。お返事はしていません。会話の中身は書かないでください。
